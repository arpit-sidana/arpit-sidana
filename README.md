## 🆕 Building now: GitViz

[**GitViz**](https://github.com/arpit-sidana/gitviz) turns an unfamiliar GitHub repository into an evidence-backed map of its product capabilities, implementation flows, architecture, and evolution.

It is designed to help people move from _“what is this codebase?”_ to _“how does this product actually work?”_ without losing the trail back to source evidence.
